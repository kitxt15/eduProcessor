# eduVirtualMachine

Учебная стековая виртуальная машина на C и C++. Ассемблер переводит текст программы в байткод, процессор исполняет его, а raylib показывает содержимое видеопамяти. Дизассемблер переводит байткод обратно в ассемблерный текст.

## Сборка на macOS

Понадобятся компиляторы C и C++, CMake 3.16 или новее, raylib и локальный заголовок `../eduStack/stack.h`. Каталог `eduStack` должен лежать рядом с каталогом проекта. Текущая сборка использует `PrintStack` и `StackVerify` из этого заголовка. В проверенном коммите `eduStack` (`b684494`) `stack.h` отсутствует, поэтому его нужно взять из рабочей копии стека.

Если используешь Homebrew, установи зависимости. [Формула raylib в Homebrew](https://formulae.brew.sh/formula/raylib)

```sh
brew install cmake raylib
```

Сборка из корня проекта

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix raylib)"
cmake --build build
```

## Запуск примера

```sh
./build/assembler example.txt -o example_bytecode.bin
./build/processor example_bytecode.bin
```

Пример рисует закрашенный круг с центром `(16, 16)` и радиусом `10`. Программа перебирает клетки от `6` до `26` по обеим осям и закрашивает те, для которых `(x - 16)² + (y - 16)² ≤ 100`. В конце она печатает `meow-meow-meow!` командой `MEOW` и останавливается на `HLT`. Затем открывается окно `Video`. Чтобы завершить процесс, закрой окно. [Исходный код примера](example.txt)

После изменений в ассемблерном тексте снова запусти `assembler`. `processor` читает готовый `.bin`.

## Дизассемблирование

```sh
./build/disassembler example_bytecode.bin
./build/assembler disasm.txt -o roundtrip.bin
cmp example_bytecode.bin roundtrip.bin
```

Дизассемблер записывает результат в `disasm.txt` в текущем каталоге и перезаписывает этот файл при следующем запуске. Переходы выводятся с числовыми адресами инструкций. При совпадении файлов `cmp` завершится с кодом `0`.

## Как устроена виртуальная машина

- Три регистра `a`, `b`, `c`, стек данных и отдельный стек адресов возврата для `CALL` и `RET`.
- 4096 целочисленных ячеек памяти. Последние 1024 ячейки, с `3072` по `4095`, образуют экран `32 × 32`.
- Адрес пикселя `(x, y)` равен `3072 + y × 32 + x`. raylib рисует ненулевые клетки красным, а нулевые оставляет на светлом фоне.

Этот код закрашивает верхнюю левую клетку.

```asm
PUSH 1
POP [3072]
HLT
```

`POP c` записывает значение в регистр `c`, а `POP [c]` — в ячейку памяти по адресу из `c`. Метки записываются как `:1`, `:2` и так далее. Команда `JMP :1` переходит к метке, а `JA`, `JB` и `JE` сравнивают два верхних значения на стеке и сохраняют их для дальнейших команд.
